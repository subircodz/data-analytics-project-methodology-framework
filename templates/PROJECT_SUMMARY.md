# Purpose

The Project Summary provides a complete overview of the analytics project.

It explains what the project is about, why it was undertaken, how it was executed, what was delivered, and the current project status.

Unlike the Executive Summary, this document is intended for analysts, contributors, reviewers, recruiters, and future maintainers of the project.
