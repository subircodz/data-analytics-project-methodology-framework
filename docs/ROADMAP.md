# DAPM Roadmap

> **Document Type:** Product Roadmap

---

# Purpose

This document outlines the planned evolution of the Data Analytics Project Methodology (DAPM).

The roadmap communicates the long-term direction of the framework and the major improvements planned for future releases.

Items included in this roadmap represent planned work and may change based on validation results.

---

# Development Philosophy

DAPM follows an evidence-driven development approach.

New features, templates, and architectural changes are introduced only after they have been validated through practical analytics projects.

The roadmap provides direction rather than fixed delivery dates.

---

# v0.2.0 — Architecture Redesign

**Status:** 🟡 Under Validation

### Objectives

- Redesign the DAPM architecture.
- Introduce Data Discovery as a dedicated phase.
- Separate Data Profiling from Data Validation.
- Position Data Cleaning between Profiling and Validation.
- Support consultant, academic, portfolio, and self-learning projects.
- Standardize framework documentation.
- Refactor project templates.

---

# v0.3.0 — Framework Expansion

**Status:** Planned

### Objectives

- Introduce domain-specific project blueprints.
- Expand template library.
- Improve validation checklists.
- Improve project documentation standards.
- Validate the methodology across additional business domains.

---

# v0.4.0 — Engineering Integration

**Status:** Planned

### Objectives

- Introduce implementation guides.
- Expand GitHub workflows.
- Improve collaboration guidelines.
- Introduce automation for documentation and template generation where practical.

---

# v1.0.0 — First Stable Release

**Status:** Future

### Objectives

- Complete validation across multiple analytics projects.
- Freeze the core methodology.
- Publish the first stable DAPM release.
- Provide long-term maintenance for the framework.

---

# Validation Projects

The following projects contribute directly to the evolution of DAPM.

- Warehouse Operations & Inventory Analytics
- Distribution Center & Logistics Analytics

Additional validation projects will be introduced as the framework evolves.

---

# Future Vision

DAPM aims to become a practical, technology-independent analytics framework that helps analysts execute consistent, well-documented, and business-focused analytics projects across different industries and technologies.
